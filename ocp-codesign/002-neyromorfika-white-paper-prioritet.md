# Нейроморфика: доработка white paper — задача на 1.5 месяца

## Context and Problem Statement

Итоговая задача группы на ближайшие полтора месяца — доработать и сдать нейроморфную white paper. У Hashim таблица из ~39 открытых вопросов по разделам, из них ~12 для обсуждения с профессором Jason. Проблемы, не раскрытые в paper: нет общей памяти между GPU и нейроморфным железом — нужен memory manager/оркестратор; gateway потребляет энергию, что противоречит главному преимуществу нейроморфики.
