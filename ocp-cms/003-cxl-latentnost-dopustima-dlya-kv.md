# Латентность CXL допустима для KV-стриминга (+270–370 нс)

## Context and Problem Statement

Распространённый аргумент против CXL — добавленная латентность. Замеры Samsung Memory Solutions Lab (Cognos + AI memory node): для KV-тиринга латентные допуски шире, чем принято считать — host DRAM ≈ CXL для стриминга.

**Из обсуждения на встрече:**

> «Латентность vs пропускная способность: для KV-тиринга латентные допуски шире, чем принято считать (host DRAM ≈ CXL для стриминга; CXL +270–370 нс при правильной настройке не вредит)» — Server - CMS _ Composable Memory System - workstream, 2026-08-19 — youtube.com/watch?v=lyw048uUPwg

## Considered Options

* Считать CXL «медленным» и не рассматривать
* Принять: для KV-потоков +270–370 нс приемлемо

## Decision Outcome

Латентность снята как блокер: CXL-пул пригоден для KV-тира при правильной настройке.

### Consequences

Фокус споров смещается на пропускную способность и стоимость, не латентность.

## Pros and Cons of the Options

### Считать CXL «медленным» и не рассматривать
* просто
* противоречит замерам
### Принять: для KV-потоков +270–370 нс приемлемо
* принято: подтверждено бенчмарками
* требует правильной настройки
