# Механизм доступа к дампу: специфицируем только «файл существует»

## Context and Problem Statement

Status dump — механизмы доступа (продолжение прошлой встречи): in-band-метод «отложить» (punt). Решение: специфицировать только требование, что файл с дампом должен существовать, без детального механизма доступа.

**Из обсуждения на встрече:**

> «Решение: in-band-метод «отложить» (punt) — специфицировать только требование, что файл с дампом должен существовать, без детального механизма доступа» — HM - DDD _ Datacenter Diagnostics and Debug - workstream, 2026-04-09 — youtube.com/watch?v=2mounN58mXw

## Considered Options

* Специфицировать механизм доступа детально
* Только требование существования файла

## Decision Outcome

Принято: требование существования файла; механизм — за вендором/транспортом.

### Consequences

Совместимо с in-band (PLDM Type 7) и out-of-band (Redfish) путями.

## Pros and Cons of the Options

### Специфицировать механизм доступа детально
* гарантия интеропа
* раздувает спеку — отвергнуто
### Только требование существования файла
* принято: гибкость
* транспортная зависимость остаётся
