# Внутри транспортного слоя — только payload, без трансформаций

## Context and Problem Statement

Архитектурное правило интеграции MIPI в PLDM/Redfish: внутри транспортного слоя трансформаций быть не должно — только payload. Участники согласились, что это нужно зафиксировать в спеке.

**Из обсуждения на встрече:**

> «Внутри транспортного слоя трансформаций быть не должно — только payload; участники согласились, что это нужно зафиксировать в спеке» — HM - DDD _ Datacenter Diagnostics and Debug - workstream, 2026-05-14 — youtube.com/watch?v=OD5X_VrTLwE

## Considered Options

* Транспорт может трансформировать payload
* Payload сквозной, транспорт прозрачен

## Decision Outcome

Принято: транспорт прозрачен, любые преобразования — на концах.

### Consequences

Требование к мостам (bridges): MIPI не делает debug-специфичных мостов, владельцы транспортов делают универсальные (пример: I3C device class for USB).

## Pros and Cons of the Options

### Транспорт может трансформировать payload
* можно подстроить под транспорт
* рассинхрон концов — отвергнуто
### Payload сквозной, транспорт прозрачен
* принято: предсказуемость
* мосты должны быть универсальными
