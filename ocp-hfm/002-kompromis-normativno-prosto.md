# Компромисс: «нормативно просто, информативно точно, поэтапно»

## Context and Problem Statement

Спор о флаге инжектированных ошибок: точный пер-ошибочный флаг (только инжектированные) vs простой глобальный флаг режима. Разрешён трёхуровневым компромиссом: нормативно — просто, информативно — точно, внедрение — поэтапно.

**Из обсуждения на встрече:**

> «Основной спор: точность флага injected-ошибок (только инжектированные) vs простота глобального флага режима — разрешён компромиссом «нормативно просто, информативно точно, поэтапно»» — HM - Hardware Fault Management - sub-project, 2026-04-24 — youtube.com/watch?v=ejManGe_-RY

## Considered Options

* Только пер-ошибочный флаг
* Только глобальный флаг режима
* Ступенчатый компромисс

## Decision Outcome

Принят ступенчатый компромисс: норма — глобальный режим, информация — точная разметка, этапность внедрения.

### Consequences

Спека остаётся внедряемой для простых устройств, не теряя точности для сложных.

## Pros and Cons of the Options

### Только пер-ошибочный флаг
* максимальная точность
* тяжело для простых устройств
### Только глобальный флаг режима
* просто
* потеря информации — одно лишь отвергнуто
### Ступенчатый компромисс
* принято
* сложнее документировать
