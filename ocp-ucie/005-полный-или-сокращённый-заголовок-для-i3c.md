## Контекст

Спор: нужна ли полная структура MTP+UMAP для I3C, где маршрутизация не требуется. Позиция Rob: MTP-заголовок нужен и для I3C (доставка на чиплет + адрес внутри); поля MTP — не лишний оверхед, а фичи (traffic classes, security clearance), для I3C неприменимые. Возможная экономия — объединить адрес UMAP и destination ID: до 3 double words (12 байт). Варианты упрощения для I3C: убрать address/opcode/tag; CRC оставить.
