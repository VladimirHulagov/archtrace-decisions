# Какие данные передаются между фазами — нет общего понимания

## Context and Problem Statement

Ключевая проблема silicon/platform интерфейса: обсуждается формат, но нет общего понимания, какие данные вообще передаются между фазами. Нужен конкретный пример данных (псевдокод), чтобы выбрать формат и решить вопрос с h…andoff.

**Из обсуждения на встрече:**

> «Ключевая проблема: обсуждается формат, но нет общего понимания, какие данные вообще передаются между фазами. Нужен конкретный пример данных (псевдокод), чтобы выбрать формат и решить вопрос с h…» — OPF - Open Platform Firmware - project, 2026-07-30 — youtube.com/watch?v=n9UqWMq7BBM

## Considered Options

* Стандартизовать формат вслепую
* Сначала примеры данных (псевдокод)

## Decision Outcome

Открыто: требуются конкретные примеры; format-of-record отложен.

### Consequences

Memory map между silicon firmware и host firmware: ACPI/PI descriptor vs собственный формат — не принято.

## Pros and Cons of the Options

### Стандартизовать формат вслепую
* скорость
* риск не того формата
### Сначала примеры данных (псевдокод)
* принято: предметно
* задержка релиза
