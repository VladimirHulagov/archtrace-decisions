## Контекст

Edge MHS был semi-private sub project под Server; сегмент edge-AI (colocation, edge-инференс вне hyperscale ДЦ) вырос. Проект передан в новый топ-левел проект AIC (AI Infrastructure, опубликован), переименован в AI Native Edge MHS и открыт. Лиды — Dave и Brian Baker (Intel); AIC возглавляют Durk (Intel) и Vincent (HPE), воркстримы AI Native Edge и AI Native Wireless. Спека AI Native Edge MHS 1.0 готовится (переименование + правки CLA), абстракт подан на OCP APAC Summit 2026.


**Из обсуждения в чате:**

> «Edge MHS переходит из Server в новый топ-левел проект AIC (AI Infrastructure, опубликован), новое название — AI Native Edge MHS; проект стал открытым (ранее semi-private) — youtube.com/watch?v=4JDMuILJJgg» — Dave (Intel), DC-MHS Public, 2026-05-20


## Решение

Edge MHS → AI Native Edge MHS в составе AIC; старые спеки MHS остаются доступны и не удаляются.

## Последствия

Тему подняли на ближайшей встрече Server project (Dave → Greg в повестку).
