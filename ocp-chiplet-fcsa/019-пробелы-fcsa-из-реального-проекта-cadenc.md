# Пробелы FCSA из реального проекта Cadence

## Контекст

Cadence мигрирует референсную платформу Physical AI (4 чиплета, авто real-time) с CSA на FCSA; IO-чиплеты (только UCIe + контроллер + PHY) — FCSA подходит лучше CSA (ортогональны CPU-архитектуре). Из практики — пробелы спеки: недостаточная предписанность форматов сообщений (для настоящего plug-and-play нужны конкретные форматы AXI-Lite/прерываний — сейчас «можно всё», но совместной работы между вендорами это не обеспечивает); fault management/RAS — главы нет (нужен draft chapter для широкого ревью, как с security); MSI packetization в спеке отсутствует (реализация готова поменять, когда FCSA определит); транспорт system control для untranslated-чиплетов не описан.


**Из обсуждения в чате:**
